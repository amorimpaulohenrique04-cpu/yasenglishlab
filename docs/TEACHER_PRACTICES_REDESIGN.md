# Teacher practices — lesson-bound authoring and final submission

Approved 2026-10-22. Supersedes independent cohort assignment, lesson bypass, immediate item correction, reinforcement rounds and spaced repetition for lesson-bound practices.

## Authoring

Three steps: information, questions, review/publication. Teacher + AAL2 and course scope remain mandatory. New drafts require a title, course, module and lesson; questions may be incomplete until publication. Authoring uses a nonredirecting save with a stable creation key and expected revision. Conflict never silently overwrites newer content.

Content v3 adds optional item settings: weight (integer 1..100, default 1, objective only), difficulty (up to 40 characters), estimatedSeconds (integer 1..14400), shuffleOptions (boolean, default false), showExplanation (boolean, default true), promptDocument (safe paragraph/list blocks with text and bold/italic/underline marks). The plain prompt remains the compatible accessible text. No raw HTML. Existing content remains readable.

## Access

One lesson may contain many practices. Published practices inherit the complete effective authorization of their lesson. Teacher cohort assignments do not grant student access. Private answer keys and unpublished content remain protected. A missing lesson link blocks publication and new starts, not historical result reads.

## Submission

The learner saves editable provisional answers without grading. Only final submission validates and grades the complete set transactionally. One submitted attempt per learner/activity; repeated final requests return the existing result. No second round, retake, review start or spaced schedule for lesson practices. Provisional answers can be resumed; abandoning an unfinished attempt does not consume the final submission.

Result score/maxScore are weighted objective points; metrics.firstTryCorrect remains a question count. Manual items remain pending human review with no automatic score. Keys and configured explanations are disclosed only after final submission. Preview uses identical semantics without persistence.

## Delivery

Violet primary actions, existing shell/tokens/motion, container-query responsive composition. The supplied image is the layout source; independent assignment/scheduling is intentionally replaced by lesson destination. Gates and visual evidence are required by the task goal.
