# Approved UI References

Estas referências são o **contrato visual** aprovado do Yas English Lab.

## Regra de precedência
Quando uma descrição textual e um screenshot divergirem **apenas em estética**, a referência visual aprovada prevalece. Regras de segurança, acessibilidade, comportamento e domínio continuam prevalecendo sobre aparência.

Uma mudança visual relevante precisa:
1. declarar qual diferença é intencional;
2. reutilizar o design system;
3. produzir evidência desktop/tablet/mobile quando aplicável;
4. atualizar a referência somente após aprovação explícita.

## Manifest
| Pasta | Tela | Responsabilidade principal |
|---|---|---|
| `login/` | Login | Entrada simples sem competir com autenticação. |
| `home/` | Início | Próxima ação: aula, progresso, prática e agenda. |
| `aulas/` | Aulas | Trilha, módulos, aula atual, live e gravações. |
| `pratica/` | Prática | Speaking, listening, pronúncia, vocabulário e recomendações. |
| `materiais/` | Materiais | Biblioteca contextual, filtros, favoritos e recentes. |
| `progresso/` | Progresso | CEFR, habilidades, consistência e progresso curricular. |
| `agenda/` | Agenda | Calendário, reservas, práticas, eventos e compromissos. |
| `perfil/` | Perfil | Conta, preferências, plano, segurança e objetivos. |
